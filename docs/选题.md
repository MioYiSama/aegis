# 基于 ABAC 理念的防代签与多维约束课程考勤系统

## 一、 项目背景与痛点剖析

高校课堂考勤是教学管理的重要环节，但传统的考勤手段长期处于“效率”与“安全/真实/准确”难以兼顾的困境。随着智能设备与远程协助技术的普及，针对传统考勤的“作弊手段”层出不穷：

1. **纯线下点名**：串行交互导致效率极低（大班更为严重），且存在“口头代答”漏洞；无法高频执行。
2. **静态/普通二维码签到**：传播泛滥。微信群、QQ 群转发截屏即可完成远程签到。
3. **超短 TTL（生存时间）动态二维码**：无法防御实时流媒体代签。作弊学生只需通过腾讯会议、飞书屏幕共享或微信视频通话，宿舍内的学生即可实时扫码完成代签。
4. **定位签到**：易受欺骗。安卓系统在 ROOT 后可通过 Xposed 模块、虚拟定位软件伪造坐标；iOS 亦可通过爱思助手等工具修改底层位置。

除此之外，还有一些共性的问题：

- **早退不可知**：常规考勤多为“一锤子买卖”，课前签到后直接溜走无法监控。
- **迟到界限模糊**：无法精细化区分“突发情况的正常迟到”与“旷课半节后的异常蹭卡”。
- **一人持多机代签**：一名学生携带多部手机前往教室，替整个宿舍完成签到。

## 二、 核心理念

本系统引入零信任安全体系中的 **ABAC（Attribute-Based Access Control，基于属性的访问控制）** 理念，将“允许签到（Grant Check-in）”抽象为一次**动态权限判决**。只有当主体、客体、环境与操作属性均满足预设策略规则时，签到行为才被判定为“有效（Valid）”：

- Subject（主体）：活体人脸检测等
- Object（客体）：经过特定编解码算法处理的二维码，使得其经过视频传输后会出现不可逆的信息丢失
- Environment（环境）：卫星定位等
- Action（操作）：签到、签退等

除此之外，我们对其他的常见问题也有应对：

1. 针对线下效率低的问题：全面采取线上+个体独立签到的方法
2. 针对早退的问题：将签到时间缩小至1分钟以内，课间和课后都进行签到
3. 针对区分正常迟到/异常迟到的问题：开课后15分钟内允许收集部分认证信息，课间由人工进行二次校验
